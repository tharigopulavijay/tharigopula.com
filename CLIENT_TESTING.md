# SIMS Business OS — client testing

Open the [online SIMS client test](https://tharigopula.com/demos/business-os.html) in a desktop browser. It contains fictional SIMS example records; no real customer data is included.

1. In **Data & Audit → Settings**, choose **SIMS example data** to explore a populated system, or **My test data** to start with an empty workspace. Switching hides the other workspace; it does not delete it.
2. The client's test entries are saved **only in that browser on that device**. Use **Data & Audit → Export & Backup** to download a backup before changing browsers or clearing site data. If opening the HTML directly as a file, back up after every session because file-based browser storage can vary.
3. **Live** is intentionally locked. Do not enter real personal, financial, or customer information into this prototype. Individual staff login, server-side access control, and a shared client database must be completed before a live rollout.

This is a usability/feature trial, not a multi-user production pilot. The [standalone HTML](public/demos/business-os.html) is available as a backup, but the online link is the recommended way to test it.
